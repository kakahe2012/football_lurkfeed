## 四、AI 内容生产流程（9 步 Agent）

详见 `docs/AI_AGENT流水线.md`

| 步骤 | Agent | 说明 |
|------|-------|------|
| 1 | 选题策划 | 按情绪配比 + 世界杯定位生成方向 |
| 2 | 热点扫描 | 发现 trending 话题 |
| 3 | 选题确认 | 选定最终选题与情绪类型 |
| 4 | 标题生成 | 10 个高 CTR 标题 |
| 5 | 内容撰写 | 情绪故事正文 |
| 6 | 内容润色 | 去重、口语化、新球迷友好 |
| 7 | SEO 优化 | 标题、描述、标签 |
| 8 | 封面处理 | 封面图 + R2 上传 |
| 9 | 发布入库 | 写入待审队列 → 人工审批 → 发布 |

后台操作入口：**AI 流水线** `/admin/pipeline`
