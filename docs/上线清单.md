## 二、域名购买与 DNS

### 2.1 购买域名

推荐注册商（任选其一）：

- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/) — 成本价、与 CDN 同平台
- [Namecheap](https://www.namecheap.com)
- [Google Domains 替代 / Squarespace Domains]

建议域名示例：`feelfootball.com`、`feel-football.com`

**填写记录：**

| 项目 | 我的信息 |
|------|----------|
| 域名 | __________________ |
| 注册商账号 | __________________ |
| 到期日 | __________________ |

### 2.2 DNS 指向 Vercel

1. 在 [Vercel](https://vercel.com) 部署项目后，进入 **Project → Settings → Domains**
2. 添加你的域名（如 `feelfootball.com` 和 `www.feelfootball.com`）
3. 按 Vercel 提示在 Cloudflare（或注册商 DNS）添加记录：

| 类型 | 名称 | 值 |
|------|------|-----|
| A | `@` | `76.76.21.21`（以 Vercel 当前提示为准） |
| CNAME | `www` | `cname.vercel-dns.com` |

4. 等待 SSL 证书自动签发（通常 10–30 分钟）

### 2.3 环境变量（生产）

在 Vercel **Settings → Environment Variables** 配置 `.env.example` 中全部变量，重点：

```env
NEXT_PUBLIC_SITE_URL=https://你的域名.com
ADMIN_SECRET=强随机密码至少32位
```

## 三、服务器与数据库部署

### 3.1 Supabase

1. 注册 [supabase.com](https://supabase.com) 创建项目
2. SQL Editor 依次执行：
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/migrations/002_analytics_enhanced.sql`
   - `supabase/seed.sql`（可选，仅测试环境）
3. 复制 API 密钥到 Vercel 环境变量

### 3.2 Vercel 部署

```bash
git push origin main
# Vercel 自动构建部署
```

本地验证：`npm run build` 必须通过。

### 3.3 Cloudflare CDN（推荐）

1. 将域名 NS 迁到 Cloudflare
2. 开启 **Proxy（橙色云）**
3. SSL 模式：**Full (strict)**
4. 可选：缓存静态资源、开启 Brotli

### 3.4 图片存储 R2（可选）

见 `docs/DEPLOYMENT.md` — AI 封面图存 R2，降低 Vercel 带宽成本。

## 四、广告系统（Google AdSense）

### 4.1 本站已实现的广告位

| 位置 | 代码位置 | 环境变量 |
|------|----------|----------|
| **瀑布流原生广告** | 每 N 篇故事插入 1 张广告卡（默认 N=7） | `NEXT_PUBLIC_ADSENSE_SLOT_FEED` |
| **Trending 侧栏下方** | 桌面右侧热门列表下方矩形广告 | `NEXT_PUBLIC_ADSENSE_SLOT_SIDEBAR` |
| **文章文中** | 阅读至约 50% 插入 | `NEXT_PUBLIC_ADSENSE_SLOT_INLINE` |
| **手机底部**（可选） | 固定底栏 | `NEXT_PUBLIC_ADSENSE_SLOT_STICKY` |

全局必填：

```env
NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_FEED_AD_EVERY=6
```

调整瀑布流广告间隔：修改 `NEXT_PUBLIC_FEED_AD_EVERY`（建议 5–8，过小影响体验，过大影响收益）。

### 4.2 AdSense 账号申请（逐步操作）

**前置条件（审核通过率更高）：**

- [ ] 网站已用**正式域名** HTTPS 可访问
- [ ] 至少 **15–20 篇** 原创或 AI 改写后的英文文章
- [ ] 有 **Privacy Policy** 页面：`https://你的域名/privacy`
- [ ] 有 About / Contact 或页脚联系邮箱（可在隐私页写 `privacy@你的域名`）
- [ ] 网站导航清晰，非空白站

**申请步骤：**

1. 打开 [https://www.google.com/adsense](https://www.google.com/adsense)
2. 使用 Google 账号登录 → **开始使用**
3. 填写网站 URL（正式域名）
4. 选择收款国家/地区（影响税务与付款方式）
5. 将 AdSense 提供的代码中的 `ca-pub-xxxxxxxx` 填入 `NEXT_PUBLIC_ADSENSE_CLIENT`
6. 重新部署 Vercel，等待 Google 抓取站点
7. 在 AdSense 后台等待审核（**1 天～2 周**）

**常见拒审原因与处理：**

| 原因 | 处理 |
|------|------|
| 内容不足 | 继续 AI 发布至 20+ 篇 |
| 无隐私政策 | 确保 `/privacy` 可访问 |
| 低质量/重复内容 | 加强 AI 润色，避免纯抄袭 |
| 无效流量 | 不要自己疯狂点击广告 |

### 4.3 审核通过后：创建广告单元

1. AdSense → **广告** → **按广告单元**
2. 创建以下单元并记录 **数据-ad-slot** 数字 ID：

| 单元名称 | 建议类型 | 对应环境变量 |
|----------|----------|--------------|
| Feed Native | 信息流 / 展示 | `NEXT_PUBLIC_ADSENSE_SLOT_FEED` |
| Sidebar Rectangle | 展示矩形 300×250 | `NEXT_PUBLIC_ADSENSE_SLOT_SIDEBAR` |
| Article Inline | 文章内嵌 | `NEXT_PUBLIC_ADSENSE_SLOT_INLINE` |
| Mobile Anchor | 锚定广告（可选） | `NEXT_PUBLIC_ADSENSE_SLOT_STICKY` |

3. 填入 Vercel 环境变量 → **Redeploy**

4. 后台 **广告管理** `/admin/ads` 查看说明

### 4.4 绑定收款账户

1. AdSense → **付款** → **付款信息**
2. 填写收款人姓名、地址（与税务一致）
3. 添加付款方式：
   - **中国大陆**：常通过西联汇款、银行电汇，或绑定 **Payoneer / 招商银行全球收款** 等
   - **香港/其他地区**：可直接绑定本地银行账户
4. 达到 **$100 美元** 最低付款门槛后，按月结算
5. 完成 **税务信息**（W-8BEN 等表格，按提示填写）

### 4.5 GA4 与 AdSense 关联（推荐）

1. [Google Analytics](https://analytics.google.com) 创建媒体资源
2. 衡量 ID 填入 `NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXX`
3. GA4 → 管理 → 产品关联 → **AdSense 关联**
4. 便于在同一后台看流量与广告收益

## 十三、本次新增能力与安全加固（v2）

### 新功能
- **视频卡片**：文章 `media_type=video` 且填写 `video_url`（仅支持 YouTube / Vimeo / 直链 mp4）后，
  前台列表会显示「▶ Video」播放角标，详情页内嵌响应式播放器。
- **批量发布 / 导入**：后台「发布 / 导入」页（`/admin/publish`）
  - 可选择多个 `.html` 文件或整个文件夹，自动提取标题/正文/首图并**安全消毒**后入库（默认进「待审核」）。
  - 可勾选现有草稿/待审文章，**批量发布或拒绝**。
- **后台登录门禁**：首次进入 `/admin` 需输入 `ADMIN_SECRET` 口令（保存在浏览器本地）。

### 安全加固（部署前必读）
1. **`ADMIN_SECRET` 必须改成强随机值**（`openssl rand -hex 24`）。
   生产环境若仍为默认值，后台与所有 `/api/admin/*` 会被**自动锁定（503）**。
2. **正文 HTML 全程消毒**：导入入库时 + 前台渲染时双重过滤 `<script>/<iframe>/onxxx` 等，杜绝 XSS。
3. **视频白名单**：只允许可信平台域名嵌入，untrusted URL 一律不渲染。
4. **安全响应头**：已在 `next.config.ts` 配置 `X-Content-Type-Options`、`X-Frame-Options`、
   `Referrer-Policy`、`Permissions-Policy`、HSTS。
5. **埋点接口防滥用**：`/api/analytics` 校验事件类型并截断超长字段。

### 数据库迁移
- 执行 `supabase/migrations/003_video_support.sql`（新增 `media_type`、`video_url` 列）。
